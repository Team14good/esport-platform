## 重新產生 PDF

修改 Markdown 或 `meta.json` 後執行：

```bash
node docs/midterm/_build/build.mjs
```

- 只產生其中幾份：`--only A,C`
- 需要 Node 22 以上、本機的 Chrome 或 Edge，並且要能連網（從 CDN 載入 marked、mermaid、paged.js）。
- 圖用 Mermaid 撰寫；使用案例圖（`usecase` 區塊）與泳道圖（`swimlane` 區塊）是自訂語法，語法說明在 `_build/usecase.js`、`_build/swimlane.js` 開頭。
- 執行結果會列出縮放比例低於 0.62 的圖（字會偏小），以及任何畫圖錯誤。
- `_build/html/` 是排版過程產生的中間檔，可以刪除。
