# 產品簡介：電競賽事管理平台

## 摘要

校際與社群電競盃賽的主辦方，現在要靠 PDF 規程、FB 公告、Discord 頻道、截圖和 email 申訴書，才能把一場比賽辦完。報名資格要人工審、對戰表要人工抽、結果靠裁判手記，申訴則靠寄信。

電競賽事管理平台把這些流程收進同一個網頁系統：主辦方開賽事、審報名、一鍵抽籤產生對戰表；裁判登錄比分；隊長上傳結算截圖、在時限內線上申訴；觀眾即時看到賽程與結果。

系統以《英雄聯盟》與《特戰英豪》為主要示範，但各遊戲的差異（每隊人數、幾戰幾勝、比分型態、報名資格）都做成設定，任何「兩隊對打、分出勝負」的遊戲都能使用。

## 要解決的問題

以 2024 第六屆大專盃電競錦標賽的特戰英豪規程為例（[來源](https://pe.ncu.edu.tw/Uploads/2024-07-02/66839de8865eb.pdf)），一場 64 隊的比賽要靠大量人工：

- **報名審核靠人工計算**：同校多隊時，以選手段位積分平均決定代表隊，全由主辦方逐筆計算。
- **抽籤與賽程分散在公告裡**：抽籤結果貼在 FB，選手要自己去找對手是誰、幾點打。
- **檢錄與遲到判定靠 Discord 與人工計時**：賽前 30 分鐘要進頻道報到，超過 15 分鐘沒開打判棄權，全靠裁判盯著。
- **結果與證據分開保存**：比分由裁判紀錄，截圖由選手「自行存證」，兩者沒有綁在一起。
- **申訴流程笨重**：要在比賽結束後 30 分鐘內 email 寄出申訴書、還要教練簽名，處理進度無從追蹤。

主辦方是最大的受害者：每多一隊報名，人工工作就多一份，出錯時也最難追查。社群與系上的小型比賽人力更少，通常用 Google 表單收報名、Excel 排賽程，問題只會更嚴重。

## 解決方案

一場比賽在平台上的流程：

1. **開賽事**：主辦方選遊戲，設定名額、賽制（必做為單淘汰）、幾戰幾勝與報名資格。
2. **報名與名額分配**：隊長建隊、提交名單（先發加替補，提交後鎖定）並報名。名額分三階段分配：優先期（預設 1 天）各校取段位積分平均最高的代表隊；先搶期由尚無正取的學校先到先得、額滿列候補；截止時名額有剩，同校第二隊依段位補位（每校最多 2 隊）。
3. **抽籤產生對戰表**：報名截止後由系統抽籤；隊伍數不是 2 的次方時自動安排輪空。
4. **檢錄**：開賽前隊長線上簽到；預定開賽 15 分鐘後仍無法開始或人數不足，系統判棄權、對手晉級。
5. **比賽與登錄**：裁判登錄每局比分；隊長上傳結算畫面截圖作為佐證。
6. **限時申訴**：系列結果確認後 30 分鐘內，隊長可線上申訴；主辦方處理後結果才確認，勝方自動晉級。
7. **觀賽**：觀眾不必登入就能看對戰表、即時比分與賽果。

申訴 30 分鐘、遲到 15 分鐘是系統固定的預設值。主辦方可以放寬，但不能縮短，以保障隊伍的基本權益。

## 與現有做法的差異

- **對比人工流程**：報名審核、抽籤、檢錄判負、申訴都在同一處完成，每一步都留紀錄，可追溯。
- **對比國外賽事工具**：[假設] Challonge、start.gg 等工具以英文介面為主，重點在對戰表與報名，沒有針對台灣校園賽常見的「同校隊數限制、段位積分換算、限時書面申訴」設計。
- **差異的本質**：坦白說，差異不在技術門檻，而在把台灣校園賽的實際規則做成可設定的流程。

## 使用者

| 角色 | 需求 | 成功的樣子 |
|---|---|---|
| 主辦方（主要） | 少做人工、規則一致、出事查得到、處理申訴與檢舉 | 從開放報名到公布對戰表不用開 Excel |
| 裁判 | 快速、正確地登錄比分 | 每場結果與證據都在同一頁 |
| 平台管理員 | 只讓真實社團成為主辦方、維護遊戲設定 | 新增遊戲不用改程式 |
| 隊長 | 知道何時打誰、有地方申訴 | 不必翻 FB 與 Discord 找賽程 |
| 選手 | 查自己隊伍的賽程與戰績 | 一個頁面看完 |
| 觀眾 | 跟上比賽進度 | 不登入也能看即時對戰表 |

隊長是「在某支隊伍裡的身分」，不是帳號類型：同一人可在一隊當隊長、在另一隊只是隊員。

## 成功標準

本專案是課程作業，成功標準分兩層：

- **產品面**
    - 主辦方可在系統內完成一場 32 隊單淘汰賽的完整流程，不需外部試算表
    - 1000 人同時送出報名時，報名數不超過名額
    - 每筆比分、截圖、申訴與判定都有時間與操作者紀錄
    - 同一套系統以不同設定跑《英雄聯盟》與《特戰英豪》兩場賽事
- **課程面**：撐得起 7 份文件與四層測試（單元、整合、端對端、壓力），並在 docker compose 下一鍵啟動。

## 範圍

| 範圍 | 項目 |
|---|---|
| 必做 | 帳號與角色權限、建隊與名單鎖定、報名與三階段名額分配、搶名額不超收、抽籤產生單淘汰對戰表、賽前簽到與逾時判負、裁判登錄每局比分、截圖佐證、限時申訴與主辦方處理、資格檢舉與取消資格頂替、自動晉級、季軍賽、觀眾看對戰表 |
| 加分 | 選手 KDA 與個人戰績、串《英雄聯盟》官方 API 自動帶入比分、雙敗或循環賽、手機推播、《特戰英豪》地圖選取流程 |
| 不做 | 必須靠官方 API 才能運作的功能（VALORANT API 需 Riot 審核並經玩家授權，[來源](https://developer.riotgames.com/docs/valorant)）、直播（只放連結）、報名費與獎金金流、防作弊、大逃殺類遊戲、帶隊老師／領隊角色 |

## 願景

讓辦一場電競盃賽不再需要表單、試算表和公告東拼西湊：報名流程從填表、審核到公布結果一氣呵成，賽程以視覺化對戰樹呈現，每一場的勝負、誰晉級、誰淘汰都即時更新，選手、隊伍和觀眾隨時上平台就能看到比賽打到哪裡。
